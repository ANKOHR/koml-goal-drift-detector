# Lessons for KOML

Explicit objectives need permitted actions and contribution assertions before a deterministic detector can evaluate activity. A goal description alone is insufficient for honest semantic detection without inference.

The synthetic tests validate the narrow assumption that planted rule violations can be recovered exactly with reconciled counts and costs. They do not validate that these rules detect all meaningful drift in real work. Corrupted activity changes decisions; corrupted labels change evaluation, demonstrating that neither is hardcoded to fixture totals.

Operating rule: preserve activity IDs, provenance and hand-checked labels separately from computed decisions, and never treat fixture accuracy as real deployment accuracy.

The evidence-based improvement in this build was strict rejection of duplicate JSON keys and nonfinite constants. Python's default decoder accepts these ambiguous inputs; the adversarial tests demonstrate named rejection rather than silent replacement. The two-week real-use improvement and verdict remain pending.
